# Editor usability pass — 30 September 2026

Codex usability worker, shared main checkout. Scope: `apps/editor/src/ui/folio-shell.ts`
and `folio-shell.css`. Existing commands, panels, identifiers, scene data and history
remain authoritative. No tests, fixtures or schema were changed.

## Decisions and changes

- Restore the existing labeled workspace navigation. Scene, Renovate, Furniture,
  Ceilings, Materials and Assistant can be reached directly. The same controls and
  event handlers remain in use. Desktop uses a compact rail; phone/tablet uses a
  horizontally scrollable strip above the viewport. Active workspaces have both
  a selected background and edge marker.
- Keep 3D, Top, Inside and Plan labels visible, including at phone width. Left/right,
  Home and End navigate keyboard focus within the view group. Enter or Space activates
  a view. Moving focus does not change the current camera.
- The More trigger supports Up/Down to open and focus the last/first action. The
  existing menu arrow navigation remains; Escape restores trigger focus. Tabbing
  away closes the menu without pulling focus back. Visible focus outlines apply
  to buttons and selects.
- Inside shows the existing live movement guidance (drag to look, WASD/arrows,
  Escape to leave), previously hidden with the old bottom chrome.
- Replace the misleading floating “Swap for one that fits” action, which merely
  opened the add catalog, with Properties and replacement options. It opens the
  existing inspector and its checked replacement controls. Selected names and
  dimensions now refresh even when the selection ID has not changed.
- At 390 px width, keep Save, undo/redo, Share and theme controls within the header.
  The cost total becomes an icon with a full accessible label; the extra Sandbox
  shortcut and inline Rename button step aside. The existing team actions menu
  remains reachable. Guided tour stays available through More on narrow canvases.
- Mobile tool panels end above the view dock, rather than covering every camera
  control. Phone view/tool targets are at least 40 px tall. Delete/undo feedback
  appears above the dock instead of covering its buttons.

Top lighting is no longer a separate toggle in Folio: the main integration owns
the shared environment for 3D, Inside and Top. Plan retains its diagram controls.
