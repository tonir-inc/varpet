# Unreal Home Wizard reference assessment

Reviewed 2026-09-26 at commit [`f021ea665728b5b2ad6909665cf99e20ab78da04`](https://github.com/amirmushichge/unreal-home-wizard/tree/f021ea665728b5b2ad6909665cf99e20ab78da04), whose commit date is 2026-09-24. Repository version: `0.2.0`. All upstream links below are pinned to this commit. No upstream code or assets were copied.

## Decision

**Adapt its evidence and review practices; do not reuse it as the browser editor.** This is a Codex-guided production workflow and a native Unreal Editor launch bridge. It is not a browser application, furniture editor, scene engine, or ready-made reconstruction algorithm. The complete tracked tree contains documentation, platform scripts, one read-only Python probe, and a project descriptor fixture. The README calls it a public beta and explicitly separates automation success from reconstruction quality. [Repository tree](https://github.com/amirmushichge/unreal-home-wizard/tree/f021ea665728b5b2ad6909665cf99e20ab78da04), [status](https://github.com/amirmushichge/unreal-home-wizard/blob/f021ea665728b5b2ad6909665cf99e20ab78da04/README.md#L64-L78).

Varpet's `apps/editor` should remain a self-contained Three.js application, with one serializable scene and shared, checked operations for person and agent edits. Native Unreal projects and shell launches would introduce a different persistence model and installation boundary without providing the missing editor controls.

## Ideas to adapt independently

- **Evidence attached to decisions.** Track source reference, measured versus inferred dimensions, confidence, and unresolved contradictions. Expose uncertainty in an inspector instead of presenting estimated rooms as measured. The source describes an evidence ledger; it does not implement this data model. [Evidence ledger](https://github.com/amirmushichge/unreal-home-wizard/blob/f021ea665728b5b2ad6909665cf99e20ab78da04/skills/unreal-home-wizard/references/logic-and-fidelity-audit.md#L5-L9).
- **Architecture and major furniture before decoration.** Stabilize room connections, openings, units, and large silhouettes before material polish. This fits deterministic procedural geometry and clear review checkpoints. [Build order](https://github.com/amirmushichge/unreal-home-wizard/blob/f021ea665728b5b2ad6909665cf99e20ab78da04/skills/unreal-home-wizard/references/build-flow.md#L11-L31).
- **Physical checks with named failures.** Check object support, floor contact, intersections, room containment, and opening clearance using scene geometry. Give failed checks object IDs and actionable reasons. The reference supplies qualitative checks and defect severity, not reusable algorithms. [Physical audit](https://github.com/amirmushichge/unreal-home-wizard/blob/f021ea665728b5b2ad6909665cf99e20ab78da04/skills/unreal-home-wizard/references/logic-and-fidelity-audit.md#L11-L34).
- **Consistent 3D review viewpoints.** Store cameras so the same room can be reviewed after edits. Preserve Varpet's constitution: no generated images or 2D previews. Do not adopt the external workflow's screenshot/top-view deliverables as project requirements. [Reference review loop](https://github.com/amirmushichge/unreal-home-wizard/blob/f021ea665728b5b2ad6909665cf99e20ab78da04/skills/unreal-home-wizard/references/logic-and-fidelity-audit.md#L17-L28).
