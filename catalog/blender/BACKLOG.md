# bpy catalog backlog

done with the group (`bpy-<lane>`) and count once imported. One lane per folder (`catalog/blender/<lane>/`), one group
per lane (`catalog/data/extra/bpy-<lane>/`). How to build: `catalog/blender/README.md`. Gaps come from
`docs/catalog-gaps.md`; styles: japandi, mid-century, scandinavian, modern organic, wabi-sabi, boho, minimalist.
